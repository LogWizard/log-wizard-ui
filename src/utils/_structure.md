# src/utils — структура

Допоміжні утиліти, без бізнес-логіки.

| Файл | Призначення |
|------|-------------|
| `logger.js` | Легкий ESM-логер без зовнішніх залежностей. Експортує `logInfo`, `logWarn`, `logError`. Кожен рядок префіксує `[YYYY-MM-DD HH:MM:SS]` (локальний час). `logInfo`/`logWarn` → stdout, `logError` → stderr. API повторює сигнатуру `console.*`. |

## Правила
- Жодних голих `console.*` у кодовій базі — тільки через `logger.js`.
- Якщо колись підключимо winston — міняємо реалізацію всередині `logger.js`, інтерфейс (`logInfo/logWarn/logError`) лишаємо незмінним.
